# Femme Fatale

مكتبة عربية رقمية لقراءة كتاب **«أنثى لا تُنسى»** مجانًا. موقع ثابت (HTML/CSS/JS فقط) جاهز للنشر على GitHub + Netlify. التصميم: وردي فاتح (Baby Pink) وذهبي.

## البنية

```
index.html            الصفحة الرئيسية
about.html            عن المنصة
contact.html          تواصل معنا
privacy.html          سياسة الخصوصية (تشمل إفصاحات AdSense وAnalytics)
404.html
robots.txt  sitemap.xml  netlify.toml

assets/
  css/style.css       التصميم العام
  css/pages.css       صفحات المعلومات
  css/reader.css      صفحات القراءة (الجداول، الصناديق، الوضع الليلي)
  js/main.js          القائمة والحركات
  js/reader.js        شريط التقدم، حجم الخط، الوضع الليلي

books/unforgettable/
  index.html          فهرس الكتاب
  front.html          المقدمات (الإهداء، رسالة الكاتبة، الاختبار الافتتاحي)
  chapter-1.html … chapter-18.html
  conclusion.html  glossary.html  references.html  appendix.html
  cover.png           ← ضعي هنا غلاف الكتاب
```

## الغلاف

ضعي صورة الغلاف باسم `cover.png` داخل `books/unforgettable/` (يفضّل نسبة 2:3، مثل 800×1200). حتى ذلك الحين يظهر غلاف مرسوم بالتصميم نفسه تلقائيًا.

- داخل كل صفحة من الكتاب: وحدتان إعلانيتان (`6007688884` بعد عنوان الفصل، و`2290256992` بعد نهاية النص)، دون صفحات إعلانية منفصلة.

## النشر

1. احذفي المجلد القديم `books/book1/` بالكامل من المستودع (الفصول القديمة وغلافها).
2. ارفعي محتوى هذا المجلد إلى المستودع (استبدال الملفات الموجودة).
3. Netlify ينشر تلقائيًا: لا حاجة لأمر بناء، و`Publish directory` هو `.`.
4. من AdSense، افتحي «المواقع» واطلبي مراجعة جديدة بعد اكتمال الرفع.
